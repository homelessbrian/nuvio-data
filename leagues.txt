# Leagues for the Nuvio + IPTV Sports page, read from TheSportsDB every day.
#
# To add a league: add a line with its name as TheSportsDB writes it (or its TheSportsDB id),
# commit, and it's in everyone's Sports page after the next daily run (or press Run workflow).
# To take one out: delete its line, or put # in front of it.
#
# The run's summary (Actions > the run > Summary) says what each line found, with ids, and
# suggests names when one isn't found.
#
# After the name, anything else is optional, each after a | :
#   regions=UK, IE      Shown without following it in: US, UK, IE, CA, AU, OTHER (or "everywhere").
#                       Leave out: only for people who follow it.
#   words=E-Prix, ...   Other ways TV guides write it (its name is always used).
#   minutes=120         How long one game or session usually lasts.
#   sport=Racing        The app's sport, if the automatic one is wrong.
#   logos               Include the league's and teams' logos (check their licence first).
#   app=guide/wwe       Show it under one of the app's own leagues instead of a new one.
#   brands              Wrestling: logos for its shows (NXT, Raw...), from its teams.
#   skip=Women, U21     For a group line (below): names containing any of these are left out.
#
# A group line adds every league in a country's list whose name contains one of the words:
#   England / Soccer: National League, Southern, Isthmian | skip=Women
# Several countries: "England, Scotland / Ice Hockey: Elite".
